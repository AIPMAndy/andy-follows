## 🛠️ Advanced Customization

### Conversational (Easy)

Tell Claude what you want:
- *"Focus more on AI product strategy"*
- *"I want deeper technical details"*
- *"Make summaries more concise"*
- *"Switch to weekly digests"*

### Direct Editing (Power Users)

All logic lives in editable markdown files:

```
prompts/
├── summarize-ai-product.md      # Product insights extraction
├── summarize-ai-investment.md   # Investment analysis
├── summarize-ai-ip.md           # Personal brand insights
├── filter-ai-relevance.md       # Relevance filtering
└── translate.md                 # Translation rules
```

Change a prompt → next digest reflects it instantly.

### Add Your Own Sources

Edit `config/sources-*.json`:

```json
{
  "twitter": ["@YourFavoriteBuilder"],
  "blogs": ["https://builder-blog.com/rss"],
  "podcasts": ["https://podcast-feed.com/feed.xml"]
}
```

Agent automatically picks them up.
